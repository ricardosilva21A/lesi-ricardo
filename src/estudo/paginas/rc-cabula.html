Receita: analisar IP/n

  1. Sub-rede = IP AND máscara. Atalho: bloco = 256 - valor da máscara no octeto do corte; maior múltiplo do bloco ≤ valor do IP.
  2. Broadcast = IP OR wildcard (= próxima sub-rede - 1).
  3. Gama = rede + 1 até broadcast - 1.
  4. Hosts = 232-n - 2.
  5. Nº sub-redes = 2n - máscara padrão (bits emprestados).
  6. k-ésima sub-rede = rede base + (k - 1) × bloco.

VLSM passo a passo

  1. Ordenar os departamentos por ordem decrescente de hosts.
  2. Para cada um: o menor h com 2h - 2 ≥ hosts → prefixo /(32 - h).
  3. Atribuir o bloco a partir do primeiro endereço livre (fica sempre alinhado).
  4. Próximo livre = broadcast + 1.
  5. Ligações entre routers: /30 (2 hosts).

Configuração TCP/IP de um host

  • Obrigatório: IP e máscara.
  • Para sair da rede: gateway (router da LAN). Para nomes: DNS.
  • Estática (manual) · dinâmica (DHCP) · automática (APIPA).
  • Conversões: binário ↔ decimal octeto a octeto; hexadecimal = 4 bits por dígito (FE80 = 1111 1110 1000 0000).

Encaminhamento IP

  • Não orientado à conexão: cada datagrama é independente, pode chegar fora de ordem. Fiabilidade = TCP nos hosts.
  • Maior prefixo ganha (mais específica). 0.0.0.0/0 = rota por defeito, só se nada mais corresponder.
  • Estático: manual, controlo total, não reage a falhas. Dinâmico: protocolos, adapta-se, gasta CPU/largura de banda, risco de loops.
  • Routers das pontas (uma só saída) podem usar só a rota por defeito.

Domínios de colisão e de broadcast

  • Colisão: cada porta de switch, bridge ou router é um domínio. Um hub e tudo o que lhe está ligado = 1 domínio.
  • Broadcast: switch não separa (por VLAN). Cada interface de router = 1 domínio. Cada VLAN = 1 domínio.
  • Contar colisão: nº de ligações a portas de switch/router.

VLANs

  • Rede lógica sobre a mesma infraestrutura; domínio de broadcast próprio; camada 2.
  • Entre VLANs: precisa de camada 3 (router-on-a-stick ou switch L3 com SVIs).
  • Adesão: porta (estática), MAC (dinâmica, VMPS/RADIUS), protocolo, sub-rede IP, 802.1X.
  • Vantagens: desempenho, segurança, gestão, custos, transparência.
  • Access: 1 VLAN, sem etiqueta (PCs). Trunk: várias VLANs, com etiqueta 802.1Q.
  • Mesma gama IP em VLANs diferentes sem router: não comunicam (o ARP não passa).
